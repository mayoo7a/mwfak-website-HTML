# Marah Website

Portfolio site of Marah Touqan. Static, no build step: open `index.html` (`website02.html` is only a redirect kept for old links). `my-work.html` is the portfolio page.

Pages: `index.html` (home), `services.html` (the four services), `my-work.html` (portfolio gallery with lightbox). Each page keeps its own CSS in one `<style>` block and its scripts at the end of `<body>`. Images are in `assets/portfolio`, tool logos in `assets/tools`. The "Get a quote" and "Start a project" buttons open WhatsApp directly.
